## Краткое резюме

Multilogin — **антидетект-браузер** и менеджер **отпечатка браузера** для агентств и MMO-команд. Работает с 2015 года. Каждый профиль изолирован на уровне fingerprint, а не только cookies.

## Возможности

### Два движка

- **Mimic** — Chromium, отпечаток как у Chrome  
- **Stealthfox** — Firefox, альтернативная изоляция  

### Остальное

- Настройка Canvas, WebGL, timezone, шрифтов, user agent  
- Отдельный прокси на профиль  
- Изоляция cookies и local storage  
- API для массового создания профилей  
- Cloud Phone — виртуальные телефоны (`MIN50`)
