## Features

### Dual browser engines

- **Mimic** — Chromium-based core for Chrome-like fingerprints  
- **Stealthfox** — Firefox-based core for alternate isolation patterns  

### Browser fingerprint

Per-profile control of Canvas, WebGL, timezone, language, screen resolution, fonts, and user agent. Fingerprints are tested daily against 50+ detection environments.

### Proxy integration

Bind one HTTP or SOCKS5 proxy per profile — standard workflow for geo-targeted ad ops and marketplace accounts.

### Session isolation

Cookies and local storage stay inside each profile; no cross-contamination between accounts.

### Automation API

Programmatically create, launch, and manage profiles — fits bulk provisioning and Selenium / Playwright / Puppeteer workflows.

### Cloud Phone

Virtual Android devices on cloud for app-based workflows. Use coupon **`MIN50`** at checkout.
